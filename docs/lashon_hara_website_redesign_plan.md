# לשון הרע לא מדבר אליי — Website Redesign & Digital Product Plan

## Objective

Rebuild [https://lashonhara.co.il/](https://lashonhara.co.il/) into a modern, conversion-focused digital platform for the "לשון הרע לא מדבר אליי" movement.

This is **not** simply a visual redesign.

The goal is to turn the existing nonprofit + ecommerce website into a modern digital movement platform that:

- Clearly communicates the mission
- Converts visitors into participants
- Makes the movement feel large, active, and alive
- Gives schools and organizations a clear path to participate
- Builds an ambassador/community ecosystem
- Uses stories and social proof to build trust
- Makes the ecommerce store easier to browse and convert from
- Creates content that can generate long-term SEO traffic
- Encourages visitors to share the message
- Makes the "השינוי מתחיל בי" commitment a real, memorable, shareable experience

---



# 1. Core Product Strategy

The current website effectively contains four products:

1. Social movement
2. Educational organization
3. Community / ambassadors
4. Ecommerce store

The redesign should give these four areas a clear hierarchy instead of presenting them as competing priorities.

## Primary funnel

```text
DISCOVER THE MESSAGE
        ↓
AGREE WITH THE MESSAGE
        ↓
JOIN THE MOVEMENT
        ↓
SHARE THE MESSAGE
        ↓
BUY / WEAR / DISTRIBUTE THE MESSAGE
        ↓
BRING IT TO SCHOOL / WORK / FAMILY
        ↓
BECOME AN AMBASSADOR
        ↓
DONATE / SUPPORT
```

The current website often pushes users toward the store too early.

The message and movement should come first.

Merchandise is a distribution mechanism for the message, not the main product.

# 6. The "What Is Lashon Hara?" Experience

The current explanatory content is informative but static.

Turn it into an interactive educational experience.

## "האם זה לשון הרע?"

Show a scenario.

User chooses:

- כן
- לא
- לא בטוח/ה

Then explain the answer.

Possible scenarios:

- Talking about someone's mistake
- Sharing something embarrassing
- Gossiping in a group chat
- Posting a negative story
- Giving legitimate criticism
- Warning someone about genuine danger

This can become one of the site's most engaging features.

It should be educational, not a legal authority.

For religious/legal definitions, clearly distinguish educational guidance from formal legal or halachic advice.

# 36. What NOT To Do

Avoid these common redesign mistakes.

## Do not:

- Add animations everywhere
- Add AI just because it sounds modern
- Rebuild the backend without understanding it
- Remove useful existing content
- Hide important information behind animations
- Create dozens of pages with no purpose
- Add huge carousels
- Use generic stock photography
- Make the store harder to use for the sake of aesthetics
- Make everything a modal
- Make the website dependent on Instagram
- Create fake testimonials
- Invent impact numbers
- Publish personal information without consent
- Generate massive amounts of low-quality AI SEO content
- Break existing SEO URLs
- Ignore accessibility
- Ignore mobile
- Optimize for design screenshots instead of real user behavior

# 43. Cursor Execution Instructions

Treat this document as the product vision and requirements baseline.

When implementing:

- Prefer small, reviewable changes.
- Keep existing functionality working.
- Do not delete existing features unless explicitly justified.
- Reuse existing APIs where possible.
- Avoid unnecessary dependencies.
- Keep components reusable.
- Keep business logic separate from presentation.
- Make the UI responsive from the beginning.
- Support RTL correctly.
- Keep accessibility in mind.
- Add loading, empty, and error states.
- Add analytics events for important actions.
- Preserve SEO.
- Preserve existing URLs where possible.
- Add redirects where URLs change.
- Do not hard-code business data that should come from the backend.
- Do not invent organization statistics.
- Do not invent testimonials.
- Do not invent products.
- Do not invent prices.
- Do not invent organizational claims.
